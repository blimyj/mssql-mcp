mssql-mcp configuration

How to set up the SQL Server MCP server, and what each setting changes for the agent using it. Every response below is real output captured from the local test server (TestShop and Inventory databases).

How to configure

Two files hold the configuration: .env for secrets and global behavior, and an optional databases.json listing the databases. Both sit in the mssql-mcp folder and are git-ignored. Your MCP client only needs the path to the server.

Build the server

Once, and again after pulling changes.

cd mssql-mcp
cp .env.example .env
npm install
npm run build

Put secrets and global settings in .env

With only one database you can stop here: the connection settings in .env define it. With databases.json present, .env just supplies passwords and global behavior.

# Connection (used when there is no databases.json)
MSSQL_SERVER=localhost
MSSQL_PORT=1434
MSSQL_USER=mcp_reader
MSSQL_PASSWORD=••••••••          # referenced from databases.json via "passwordEnv"
MSSQL_DATABASE=TestShop
MSSQL_TRUST_SERVER_CERT=true

# Behavior
MSSQL_READONLY=true              # only SELECT / WITH
MSSQL_OUTPUT=compact             # or pretty
MSSQL_EXCLUDE_SCHEMAS=           # comma list, hidden on every database
MSSQL_ALLOW_EXCLUDED_OVERRIDE=true
MSSQL_RATE_MAX=3                 # requests per window (0 = off)
MSSQL_RATE_WINDOW_MS=10000
MSSQL_MAX_CONCURRENT=1
mssql-mcp/.env

List databases in databases.json (optional)

Each entry inherits from defaults. Keys are the names agents pass as db. This is the file the test server runs with:


        
mssql-mcp/databases.json · template: databases.example.json

      


      

        
Register it with your client

          
The client starts the server itself. No secrets go here.

        

          
opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mssql": {
      "type": "local",
      "command": ["node", "/path/to/mssql-mcp/dist/index.js"],
      "enabled": true
    }
  }
}

          
.mcp.json (Claude Code)
{
  "mcpServers": {
    "mssql": {
      "command": "node",
      "args": ["/path/to/mssql-mcp/dist/index.js"]
    }
  }
}

        

      


      

        
Restart the client and check

          
Settings are read when the server starts, so restart the client after any change.

        
$ opencode mcp list
●  ✓ mssql connected

      

    

  


  
  

    
Settings reference

    
Per-database keys go in a databases.json entry or in its defaults. Environment
      variables go in .env (or the client's env block).

Precedence: a database entry overrides defaults, which override built-in
      defaults. User and password fall back to MSSQL_USER / MSSQL_PASSWORD. Variables set
      in the client's env block override .env.
